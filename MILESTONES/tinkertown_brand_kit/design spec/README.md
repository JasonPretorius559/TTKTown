# Tinkertown Playful Brutalist Brand Kit

This package contains the working visual direction and implementation specification for Tinkertown's Playful Brutalist brand direction.

## Files

- `TINKERTOWN_PLAYFUL_BRUTALIST_SPEC.md` — full Codex implementation/design specification.
- `tinkertown-playful-brutalist-brand-kit.png` — selected full brand-kit visual.
- `tinkertown-brand-directions-moodboard.png` — original five-direction exploration moodboard for reference.

## Selected Direction

**Option 4 — Playful Brutalist**

Core idea: **Little People. Big Stories.**

Primary palette: black, white, tomato red, soft yellow.

Primary typography direction: Montserrat Black / ExtraBold with Inter for supporting UI text.
